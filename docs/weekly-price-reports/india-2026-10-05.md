**Market scope:** India (`IN`); `INR` only when an official provider page explicitly publishes it  
**Source rule:** Provider-owned public pages opened directly; no search snippets, aggregators, blogs, forums, currency conversion, login, purchase, cancellation, or account access  
**Personal-data boundary:** This report is research only. It does not modify `lib/catalog.ts`, app code, user subscriptions, expected charges, billing sources, renewals, cancellation records, settings, or cloud data.

## Run overview

All **23 current catalog services** were assessed against the existing reference labels in `lib/catalog.ts`. Four services exposed clearly India- or INR-scoped recurring wording suitable for human review: **Amazon Prime, Spotify, Apple Music, and Audible**. The remaining services were classified as `context-required` or `manual-only` because the directly opened page showed another currency or market, a promotion or eligibility condition, a placeholder, an account-gated price, an unreadable/dynamic page, or no verifiable numeric recurring price.

The report deliberately keeps introductory offers, trials, students, household/family terms, seats, bundles, taxes, app-store or carrier billing, and legacy/account-specific pricing separate from ordinary recurring references. No amount was converted into INR.

## No-change / no-proposal conclusion

No service qualified for `no-change-confirmed` because this run did not establish a previously approved India/INR baseline for the remaining reference labels. This is intentional: a current provider page can confirm that a plan exists without proving a stable India recurring amount. In particular, USD, LKR, GBP placeholders, U.S.-resident restrictions, account-gated prices, tax-exclusive prices, seat pricing, trials, student offers, family conditions, and dynamic failures are not interchangeable with India/INR recurring references.
